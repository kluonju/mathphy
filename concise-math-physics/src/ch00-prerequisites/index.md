# 第0章 预备知识

本章汇集后续各章常用的数学语言与工具：数集与逻辑、三角恒等式、微积分要点、指标记号与爱因斯坦求和约定、向量分析基础，以及线性代数的基本概念。已修过高等数学、线性代数课程的同学可快速浏览，需要时查阅相应小节。

## 本章要点

- 数集 \\(\mathbb{N},\mathbb{Z},\mathbb{R},\mathbb{C}\\) 与逻辑符号
- 常用三角函数恒等式
- 导数、积分与多元微积分概要
- Kronecker 符号 \\(\delta_{ij}\\)、Levi-Civita 符号 \\(\varepsilon_{ijk}\\) 与爱因斯坦求和约定
- 向量代数（点积、叉积）与 \\(\nabla\\) 算符简介
- 向量空间、基、矩阵与特征值
