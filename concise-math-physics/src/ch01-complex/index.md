# 第1章 复变函数

复变函数论是物理学和工程学广泛使用的强大分析工具，学习掌握这个理论十分必要（见讲义 `lecture/complex/`）。数集、逻辑符号与函数的基本概念见[第 0 章](../ch00-prerequisites/index.md)。

本章涵盖：复数、复变函数、复变积分、复数级数、留数定理及应用、鞍点/最速下降等渐近方法。

## 本章要点

- 复数代数与极坐标
- Cauchy–Riemann 条件与解析函数
- 柯西定理、柯西公式
- Taylor / Laurent 级数与留数
- Laplace / 驻相 / 鞍点法与 Stirling、波包、Airy 等应用（见[鞍点近似](07-saddle-point.md)）
