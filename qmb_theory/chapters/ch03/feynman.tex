\section{Feynman 图}

\subsection{微扰展开的图示}

把 $U_I$ 或 $S(\beta)$ 按 Dyson 级数展开后，每一项用 Wick 定理变成 $G_0$ 线与相互作用顶点的乘积。用图表示：
\begin{itemize}
  \item 有向实线：自由传播子 $G_0$（向上粒子、向下空穴）；
  \item 虚线或波浪线：相互作用（瞬时库仑、声子等）；
  \item 顶点：动量、频率、自旋守恒。
\end{itemize}

\subsection{零温规则要点（Gross / Fetter--Walecka）}

\begin{enumerate}
  \item 每条 $G_0$ 线：$\mathrm{i}G_0(k)$（约定随教材；注意 $\mathrm{i}$ 的位置）；
  \item 每条相互作用：$ -\mathrm{i}v_{\mathbf{q}}$（或等价约定）；
  \item 每个顶点：$(2\pi)^4\delta^{(4)}(\sum k)$；
  \item 内部动量：$\int\mathrm{d}^4k/(2\pi)^4$；
  \item 每个费米圈：额外 $(-1)$；等时线取 $t\to t^+$；
  \item 对称因子：图的自同构群阶的倒数。
\end{enumerate}
有限温：把 $\int\mathrm{d}\omega/2\pi$ 换成 $\beta^{-1}\sum_n$，并把 $G_0(\omega)$ 换成 $\mathcal{G}_0(\mathrm{i}\omega_n)$（见 Matsubara 规则节）。

\subsection{连通图与连锁集群}

热力学势与基态能移由连通真空图决定；单粒子 $G$ 的修正来自带两条外腿的连通图。连锁集群：
\begin{equation}
  \langle\Phi_0|U|\Phi_0\rangle
  =\exp\bigl(\langle\Phi_0|U|\Phi_0\rangle_{\ell}\bigr),
  \qquad
  \ln(Z/Z_0)
  =\text{连通真空图}.
\end{equation}

\subsection{自能图}

1PI 图之和为 $\Sigma$。一阶：Hartree（密度泡）与 Fock（交换）。二阶短程常含日落图
\begin{equation}
  \Sigma^{(2)}(k)
  \sim
  \sum_{k_1k_2}
  |V|^2\,
  G_0(k_1)G_0(k_2)G_0(k-k_1+k_2).
\end{equation}

\subsection{Hugenholtz 图}

对瞬时密度--密度相互作用，把直接与交换顶点合并为反对称化粗点，图更少、对称因子更清晰。

\begin{note}
图既是计算处方，也是过程叙事：哪条线是粒子/空穴、何时交换动量。读图能力决定能否判断长波/低能主导过程。
\end{note}
